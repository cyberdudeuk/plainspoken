# Changelog

## 2.5 (28 Oct 2026)
- **Skills** (new Practise tab): 13 short lessons, each with aims, key points, a practice task you can score, a three-question check with reasons, and a saved reflection. Six speaking skills join the core practice; seven **Working relationships** lessons (presence, noticing without assuming, feedback, hard-going conversations, saying no, joining and redirecting, calming a conflict) form a separate module.
- Three new role-plays: saying no to a request, getting a word in, two colleagues disagree (15 in total).
- **Facilitator mode** in the Library: delivery plan, ground rules, final practice task, a 10-criterion rubric, suggested thresholds, a self-review that tracks your trend, and an action-plan template.
- Five new frameworks; two new commendations (Well rounded, Good colleague); a new daily cue.
- Source: adapted from the author's own communication course guide, written in a personal capacity. Lesson and course titles renamed (D13). Work-account metadata in the source file was not carried into the repo (D15).
- Quick-check options are shown in a shuffled order so answers cannot be guessed by position (D17).
- Build: stamps now come from the last commit that changed the app, so CI rebuilds match (D18); page metadata licence corrected (D19).
- Fixes: a hard-coded version label (D14); wide tables and five tabs caused sideways scrolling on phones (D16).
