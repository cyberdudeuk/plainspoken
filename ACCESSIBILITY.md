# Accessibility statement

Plainspoken aims to meet WCAG 2.2 level AA.

- Visible keyboard focus; all actions are buttons or links.
- Colour is never the only signal (pills carry text; charts carry text alternatives).
- Body text uses Atkinson Hyperlegible, designed for low-vision readers.
- Motion (sound ripples, pulses) is switched off when the device asks for reduced motion; celebrations can be turned off in Settings.
- Light and dark themes follow the device.

**Known gaps:** not yet tested with the full range of screen readers (NVDA, JAWS, VoiceOver, TalkBack); dictation depends on the device keyboard; charts are simple SVGs without data tables beyond the Progress tables.

Report a problem by opening an issue. Last reviewed: 28 October 2026.
